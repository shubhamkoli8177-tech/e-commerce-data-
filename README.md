# Amazon Sales Data Analysis Dashboard using Excel
my-fist-repository 
Amazon Sales Data Analysis Dashboard using Excel

Project Overview

This project focuses on analyzing Amazon sales data using Microsoft Excel. An interactive dashboard was created to understand sales performance and explore key business insights.

Tools & Techniques

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Charts and Visualizations
- KPI Cards
- Interactive Slicers

Dashboard Features

- Total Profit and Average Sales KPIs
- Rating, Discount, and Quantity metrics
- Sales analysis using charts
- Product and category analysis
- Interactive filters using slicers
- Geographic visualization using a map

Project Objective 

The objective of this project is to analyze sales data, identify useful patterns, and present business insights through an interactive Excel dashboard.

Skills Demonstrated

Excel Data Analysis, Data Visualization, Dashboard Design, and Business Reporting.
